## Reflection

Solving these HackerRank problems helped me understand how algorithmic thinking can be applied to practical programming problems. I learned to focus not only on getting the correct output but also on improving time and space efficiency. Problems such as Diagonal Difference and Compare the Triplets helped strengthen my understanding of loops, arrays, and basic problem-solving techniques. Dynamic Array introduced sequence-based data handling and the use of XOR for selecting indices. Time Conversion improved my understanding of string manipulation and conversion between different formats. Sparse Arrays showed how frequency counting can be optimized using a hash map instead of repeatedly searching through all strings.

Overall, these problems helped me recognize the importance of choosing appropriate data structures and analyzing complexity before implementing a solution. This activity also improved my confidence in writing clean, structured, and efficient C++ programs.
